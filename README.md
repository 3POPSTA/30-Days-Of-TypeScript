## 🎯 How It Works: The 4-Pillar Daily Learning Experience

Each day in this curriculum is structured for rapid, engaging, and practical learning:

1. **📖 In-Depth Guide (`README.md` / `0X_day_*.md`)**: Comprehensive explanations, syntax deep-dives, visual tables, and real-world production use cases *(Tip: Press `Ctrl + Shift + V` in VS Code to preview)*.
2. **💻 Runnable Lesson (`lesson.ts`)**: Executable code demonstrations showing concepts live with terminal output.
3. **🎯 Interactive Coding Challenge (`challenge.ts`)**: Bite-sized, interactive coding tasks designed for hands-on practice. No distracting boilerplate, no spoilers—just clear requirements, helpful hints, and starter templates.
4. **📘 Official Solutions & Explanations (`solutions.md`)**: Full annotated solutions for every challenge, explaining *how* and *why* they work along with Pro-Tips and common gotchas.

## 🗺️ 5-Week Roadmap

- **Week 1: Foundations & Core Type System (Days 01-07)**
  Compiler setup, primitive types, special types (any, unknown, never, void), arrays, tuples, objects, type aliases, and intersections.

- **Week 2: Control Flow, Functions & Interfaces (Days 08-14)**
  Union types, literal widening, type narrowing, custom type predicates, discriminated unions, function overloading, and interfaces.

- **Week 3: OOP, Enums & Generic Architecture (Days 15-21)**
  Interface vs type comparison, classes with access modifiers, abstract classes, enums vs `as const`, generic functions, constraints, and generic data structures.

- **Week 4: Advanced Type Metaprogramming (Days 22-28)**
  `keyof`, indexed access, mapped types, key remapping, template literal types, conditional types, the `infer` keyword, and utility types.

- **Week 5: Production Patterns, Async & Capstone (Days 29-30)**
  Strict async patterns, Result types, safe retry mechanisms, and an end-to-end event-driven workflow engine.

## ⚡ Quick Start

### 1. Requirements & Editor Tip
- Node.js (v18 or higher)
- npm
- **VS Code (Recommended)**: Use `Ctrl + Shift + V` (or `Cmd + Shift + V` on Mac) to preview any `.md` guide in rendered Markdown mode.

### 2. Setup
```bash
git clone https://github.com/3POPSTA/30-Days-Of-TypeScript.git
cd 30-Days-Of-TypeScript
npm install
```

### 3. Interactive Terminal Dashboard
Launch the central interactive dashboard to view and run any day's lesson or challenge:
```bash
npm start
```

### 4. Running Daily Lessons
Execute runnable code examples for any day:
```bash
npm run day:01
npm run day:15
npm run day:30
```

### 5. Solving Hands-On Coding Challenges
Open `<Day_Folder>/challenge.ts`, complete the `// TODO` tasks, and run your code to verify the results:
```bash
npm run challenge:01
npm run challenge:15
npm run challenge:30

# Or execute with tsx directly:
npx tsx 01_Day_Introduction/challenge.ts
```

💡 *Need help or want to compare your answer? Check out `<Day_Folder>/solutions.md` for complete solutions and pro-tips!*

### 6. Automated Testing & Verification
```bash
# Run lessons test harness
npm test

# Verify all 30 challenge workbooks execute cleanly
npm run test:challenges

# Run strict type checking across the entire project
npm run typecheck
```
