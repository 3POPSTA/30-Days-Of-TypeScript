## 5-Week Roadmap

- **Week 1: Foundations & Core Type System (Days 01-07)**
  Compiler setup, primitive types, special types (any, unknown, never), arrays, tuples, objects, type aliases, and intersections.

- **Week 2: Control Flow, Functions & Interfaces (Days 08-14)**
  Union types, literal widening, type narrowing, custom type predicates, discriminated unions, function overloading, and interfaces.

- **Week 3: OOP, Enums & Generic Architecture (Days 15-21)**
  Interface vs type comparison, classes with access modifiers, abstract classes, enums vs as const, generic functions, constraints, and generic data structures with TTL caching.

- **Week 4: Advanced Type Metaprogramming (Days 22-28)**
  `keyof`, indexed access, mapped types, key remapping, template literal types, conditional types, the `infer` keyword, and complete utility types masterclass.

- **Week 5: Production Patterns, Async & Capstone (Days 29-30)**
  Strict async patterns, Result types, safe retry mechanisms, and an end-to-end event-driven workflow engine.

## Quick Start

### 1. Requirements
- Node.js (v18 or higher)
- npm

### 2. Setup
```bash
git clone https://github.com/3POPSTA/30-Days-Of-TypeScript.git
cd 30-Days-Of-TypeScript
npm install
```

### 3. Interactive Dashboard
Launch the terminal dashboard to view and run any day:
```bash
npm start
```

### 4. Running Daily Lessons
Execute runnable code examples for any day:
```bash
npm run day:01
npm run day:15
npm run day:30
```

### 5. Running Hands-On Coding Challenges
Test your implementation against the built-in verifier:
```bash
npm run challenge:01
npm run challenge:15
npm run challenge:30

# Or execute with tsx directly:
npx tsx 01_Day_Introduction/challenge.ts
```

### 6. Automated Testing & Verification
```bash
# Verify all 30 daily lesson files
npm test

# Verify all 30 challenge workbooks
npm run test:challenges

# Run strict type checking across the entire project
npm run typecheck
```
